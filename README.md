# Emute ERP - Sistema de Gestão Hospitalar

Bem-vindo ao projecto **Emute ERP**. Este é um sistema moderno de gestão hospitalar construído com Laravel, Inertia.js e Vue.js.

## 🚀 Como Começar

Para instalar o projecto no seu computador, siga o guia detalhado presente no ficheiro:

👉 **[GUIA DE INSTALAÇÃO (INSTALLATION_GUIDE.md)](./INSTALLATION_GUIDE.md)**

## 🛠️ Tecnologias Utilizadas

- **Backend:** Laravel 11.x
- **Frontend:** Inertia.js (Vue 3)
- **CSS:** Tailwind CSS
- **Ícones:** Lucide Vue Next
- **Base de Dados:** MS SQL Server
